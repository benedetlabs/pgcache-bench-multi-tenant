# Multi-Version PgCache Verification Results

> 🇧🇷 **[Versão em português](README-pt.md)**

This directory contains benchmark verification runs comparing new releases of **PgCache**:
- [**PgCache 0.6.3**](0.6.3/README.md)
- [**PgCache 0.6.4**](0.6.4/README.md)
- [**PgCache 0.7.0**](0.7.0/README.md)

All tests were executed in the multi-tenant SaaS workload (500k orders, 2M order items, 200 tenants, 8 statements per dashboard query) using the repository's dynamic warmup (`warm_until_settled`) protocol.

## 2. Key Observations

1. **Perfect Query Cacheability**:
   Every query generated by the eight-statement multi-tenant dashboard reached a **100.0% hit ratio** after warming across all three versions. The query space expansion across 200 tenants did not degrade cacheability.

2. **Throughput Scaling**:
   Versions **0.6.3** and **0.6.4** exhibit nearly identical high-throughput profiles, reaching up to ~1,370 rps on the read workload and sustaining over 800–900 rps under a 10% write ratio.

3. **PgCache 0.7.0 Profile**:
   Version **0.7.0** successfully passed all compatibility and cache tests with 100% hits. In single-machine Docker Desktop testing, concurrent writes introduce higher CPU utilization for background CDC replication compared to 0.6.3/0.6.4. Official multi-node Kubernetes execution (where PgCache and PostgreSQL origin run on distinct physical nodes) will provide clean isolation for 0.7.0.

./scripts/run-tag-verification.sh 0.7.0 5
